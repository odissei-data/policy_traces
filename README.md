# Government Documents citing Social Science Data Infrastructure

A static search page over Dutch government documents (Kamerstukken, bijlagen, Handelingen,
Kamervragen, Staatscourant on officielebekendmakingen.nl) that cite research built on CBS microdata,
the LISS panel or ODISSEI Grants, or that mention those data by name.

Each record shows document metadata, a link to the original, the cited publications and, per citation,
a short citing passage (at most 300 characters). The documents themselves are not stored here.

- `index.html`, `style.css`, `app.js`: the page (no framework, no build step)
- `data/documents.json`, `data/publications.json`, `data/about.json`: the data, generated by the
  OpenOverheid scan of the ODISSEI knowledge graph publication lists

Served as GitHub Pages from the `main` branch root. To view locally: `python3 -m http.server` in this
folder, then open http://localhost:8000.

Not yet covered: Woo documents on open.overheid.nl (that search service was down during the scan).
Internal preview: the page is reachable by anyone with the link.
